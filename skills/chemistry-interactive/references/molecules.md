## Cách dùng file này

```
1. Tìm tên chất user yêu cầu trong bảng trên
2. Lấy CID → dùng URL: https://embed.molview.org/v1/?mode=balls&cid={CID}&bg=white
3. Điền CTPT, M vào artifact template
4. Nếu không tìm thấy → thử tên IUPAC trực tiếp hoặc báo user
```
